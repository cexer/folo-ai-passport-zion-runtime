# ZION 内置最小小智实验

实验分支为 `feature/builtin-xiaozhi`，基于本地当前 ZION 0.4.5 工作区和随身小智提交 `72da544d1b51678f5d88967adc299b3aec956946`，未修改原项目。本分支必须使用 **ESP-IDF 6.0.1**，不能使用原 ZION 的 5.5.3 环境。

## 实测体积

共用代码后的 APP 约 **2.33MiB**，可启动 BIN 约 **2.39MiB**。ZION 0.4.5 与独立最小小智的 APP 分别存放时合计约 **3.44MiB**，合并链接减少约 **1.11MiB**。

factory 分区按实测收紧到 **0x260000 / 2.375MiB**，cardid、store、OTA 记录的地址不变。相比普通 ZION 的 2MiB factory 加上独立最小小智的实际槽位，可分配空间多约 **1.53MiB**。仍受对齐和连续空闲段约束，不能据此保证任意固定数量的玩法。内置小智不占外部玩法槽位，仍可保留最多 8 条外部槽位记录。

精确大小、SHA-256、分区和 ELF 身份见 `release/*.bin.json`，对应 ELF、MAP、配置保存在 `dist/zion-with-xiaozhi/`。小 BIN 只省略了已校验 8MiB 合并镜像末尾的擦除态填充；所有已初始化镜像、校验和及分区 MD5 均经过校验。

## 功能与实现

- 列表第一项为内置小智，可启动、设为默认，管理页明确禁用删除。
- 启动时写入一次性标记，软件复位后在**同一 APP 镜像**内进入小智；长按 OK 复位返回 ZION。两种模式不会同时初始化显示、音频、联网任务。
- 保留按住上键开机跳过默认玩法的方式。冷启动、异常复位不会把遗留请求当作进入小智的许可；标记保存失败也不会启动。
- 默认设置互斥：设内置小智为默认时清除外部默认；取消内置默认后不恢复旧外部默认。设置外部默认时取消内置默认。
- 内置小智复用 ZION 保存的 Wi-Fi，没有有效网络时仍可使用原热点配网回退。小智界面仅含文字、1bpp 字体、文字激活码、电量和音量操作；不打包预录提示音、外置资源，也不允许自行更新固件。ZION 自己的官方小程序码保留。

这里实际合并了源码进行链接，不是拼接两个 BIN。Wi-Fi、TLS/PSA 加密、RTOS、LVGL、底层驱动库仅链接一份；两套板级初始化仍按模式分别使用。本实验不链接 ZION 的 4bpp UI 子集，保留原完整单色字体用于玩法名称。

## 构建

激活 ESP-IDF 6.0.1，在本项目执行：

```powershell
.\tools\build-with-xiaozhi.ps1
```

脚本使用 `sdkconfig.with-xiaozhi.defaults` 与 `partitions.with-xiaozhi.csv`，在 `build-final` 构建、合并、校验并归档。`tools/package_minimal.py` 可重复校验产物。本次适配了驱动依赖声明、Flash 结构体头文件和检查返回值的 PSA SHA-256；安装器仍会拒绝包哈希校验失败的安装。

启动实测发现 bootloader 另有一份 Kconfig 范围，会静默恢复旧 factory 尺寸。已修正范围，构建脚本必要时强制重新配置旧 bootloader，打包强制拒绝 APP/分区表/引导程序的尺寸不一致，且发布镜像不允许携带已初始化 NVS 数据。

**本分支改变了 factory 大小，不能使用旧 ZION 的 2MiB factory 更新器，也不能把它作为普通子玩法安装。** 有意通过 USB 安装时，需考虑扩大的 factory 是否覆盖旧玩法，并正确重置 OTA 选择。本次没有写入真机 Flash。

## 验证结果

- 正式配置构建、产物校验：**通过**。符号检查确认不含 4bpp 字体对象和内嵌 OGG 提示音，最小小智的图片解码器也已移除。
- 对实际内置启动标记代码进行主机测试：**通过**一次性请求消费、冷启动/异常逃逸、持久化失败、默认设置持久化及返回。
- 专用测试构建通过真实 NVS 辅助函数写入一次请求，执行模拟器中的真实软件复位，进入正式入口并初始化内置小智。**验证通过至不受支持的 Wi-Fi 调用**，未发生提前崩溃或布局拒绝。交付脚本强制关闭注入，打包器在写入任何发布文件之前拒绝测试注入标记。
- 同一测试构建还以分两次输入的 `abc` 校验 PSA 流式 SHA-256 的已知答案，无需网络仿真即可验证本次迁移的加密接口。
- 使用 IDF 5.5.3 测试固件直接复用未改写的 ZION 渲染器，模拟目录/NVS/启动服务：列表、禁止删除、默认星号、启动分派通过；同样验证了最小小智文字渲染器的待机、激活、音量页面。这不代表真实联网或语音验收。
- ZION 实际流式 C 解析器/分配器接受独立最小小智，并可与本地 138 样本同时分配。集成布局能单独分配原版 725 样本，但先分配时钟后再加 725 会因连续布局不足而失败。这些是分配测试，不是真实刷写安装。
- PassportSim 当前 Wi-Fi HLE 固定匹配 IDF 5.5.3，拒绝 IDF 6 正式镜像；完整启动/联网/语音测试仍受模拟能力限制，没有修改版本字符串绕过检查。
- 继承的全仓静态门禁**未通过**：导入的上游组件文档缺少本仓库要求的中英文配对，旧检查还沿用原字体/构建方案。未宣称它通过正式发布门禁。独立小智的上游整套测试另有原先已删除板型的夹具失败。
