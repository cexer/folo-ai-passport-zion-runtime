# Zion 使用说明

Zion 自身界面文字使用小型 4bpp 抗锯齿字库，电量使用配套小字，
列表编号、大小、版本行保留原来的紧凑字体和字号。
玩法名称中不在界面子集的字符回退到完整 1bpp 中文字库，保留原有字符覆盖。

## 日常按键

主列表包含玩法、“安装玩法”和“设置”。上下键移动选择，超过四行会滚动。
元数据最多支持八个槽位，实际能装几款取决于空间。短按 OK 启动一次，长按
OK 进入管理。标题**后面的星号**表示默认玩法。电量有进度背景；无法读取时
显示问号。
主列表底部固定显示左侧“短按OK启动”和右对齐的“长按OK管理”，
状态消息不会覆盖列表的操作说明。

卡片信息是设备槽序号、APP 槽容量和固件版本，不是社区玩法编号或下载包大小。
关联资源还会占用总空闲空间。有些官方包没有内嵌标题，会显示固件工程名。
对齐要求和资源占用会形成碎片，因此“空闲”与“连续”不是同一个数。

## 默认启动，以及怎样留在 Zion

长按 OK 进入管理，选择“设为默认”或“取消默认”。设置保存在设备上，并绑定
具体镜像，不会因为列表序号移动而指向另一款玩法。冷启动初始化后，会留出
约 1.8 秒取消窗口，再进入有效的默认玩法。

**按住上键再开机，直到看到列表；或在取消窗口中按任意键，即可留在 Zion。**
软件返回、崩溃或看门狗恢复时不会立即再次启动默认玩法。任意第三方固件不保证
都能长按 OK 返回：优先用该玩法自己的返回功能，或按住上键重启。集成
`zion_hook.h` 的子应用可以返回并跳过一次默认启动。
切换会重启进入另一份固件，不是同时运行多个玩法。

**进入玩法后，Zion 的蓝牙连接和安装服务会结束。** 小程序显示断开、暂时无法
重新连接 Zion 的安装服务，是此时的正常限制。需要继续安装或管理时，同时按
开机键和上键，直到回到 Zion 列表，再从小程序重新连接。玩法可能提供自己的
另一套蓝牙服务；仅去掉主动断连，也无法让原连接跨设备重启保留。

## 删除玩法

选中玩法长按 OK，选择“删除玩法”，再选择“确认删除”。确认页默认选中
“返回”；短按 OK 执行当前选项，长按 OK 返回。

删除会清除匹配的默认设置，先持久化移除 APP 及其关联 DATA 记录，再擦除相应
区域并释放空间，保留其它玩法。共享 NVS 不属于独立玩法空间，不会被一并清空。
清理中断或失败后留下的未完成安装可从列表删除，不能启动或设为默认。

如果记录已成功移除，但物理擦除失败，界面会提示清理未完成，不会谎报仍然安装，
也不会回滚到可能已擦除的内容。后续分配仍会先擦除目标区域再使用。

## 配置 Wi-Fi

选择“设置 → Wi-Fi 状态与配网”。设备会开启无需密码的临时热点。手机连接屏幕
所示名称，提示没有互联网时保持连接。设备会引导手机自动弹出配网页；如未弹出，
手动打开 `http://192.168.4.1`。能否自动弹出取决于手机系统设置。

网页自动扫描附近的 2.4 GHz Wi-Fi，选择网络即可，也可点“重新扫描”刷新列表。
加密网络填写路由器密码，开放网络无需密码。网页先确认收到设置，再触发联网并查询实际结果。
连接成功后才保存网络。成功页面尝试打开官方微信小程序，同时保留打开按钮和离线小程序码。
网页收到成功结果后，热点约 10 秒后关闭；网页未确认结果时，约 90 秒后关闭。
请让手机恢复原 Wi-Fi 或移动网络。失败时保留热点，方便重新配网。
小程序唤起受手机系统、浏览器和微信限制，尚未在所有手机上验收。
“更换 Wi-Fi”会清除 Zion 保存的网络，并开启新的配网会话。长按 OK 返回列表。
也支持官方小程序通过 BLE 配网。子玩法可能有自己独立的配网流程。

## 从官方社区安装

列表使用“+ 安装玩法”和“> 设置”前缀，将启动器操作与普通玩法区分。
选择“安装玩法”直接展示官方微信小程序码，提示“微信扫码打开小程序”。
这是官网提供的小程序码图案，不是包含社区网址的普通二维码。安装失败后，
退出结果页再选择“安装玩法”，会重新显示二维码以便重试；退出前保留失败信息。

使用微信扫一扫进入官方小程序后，选择玩法、点击小程序安装，再选择
已配对设备。手机经 BLE 下发安装请求，Zion 使用已配置的 Wi-Fi 直接下载；
不是通过这条蓝牙连接上传整个 BIN。

Zion 先只探测包含分区表和首个有效 APP 头的文件前缀（590 约 64 KiB），关闭连接后
分配空间，再完整传输一次 BIN，同时解析、计算哈希、写入 APP 和资源。
官方下载接口忽略 HTTP Range 时也可使用此流程；APP 头位于较后位置的稀疏布局需要更大的前缀。
报告成功后自动启动新玩法。空闲时短按 OK 返回；安装中长按 OK 会出现取消确认。
临时读超时会有限次重试。

安装失败不会清除已保存的 Wi-Fi。重新进入小程序安装会话时，设备按实际联网状态
报告就绪，不再把上一次安装错误当成未配网；屏幕仍保留失败详情。
手机小程序自身仍可能要求重新连接其会话。

安装自动开始，不增加设备确认步骤。官方下载链接可匹配公共元数据且大小、SHA-256
一致时，屏幕展示社区标题；否则明确使用“工程”标注固件项目名。
同时展示
下载大小、APP 加资源的预留安装占用，以及检查、写入、校验的整体进度。
安装占用包括槽位对齐和元数据，并非只计算资源已初始化的字节。
解析完成前，占用显示“正在解析”；无法获取名称时明确标注。
小程序请求不包含社区标题，名称查询是独立的小型元数据请求，不是第二次完整下载 BIN。
进度包含布局探测、空间准备、传输和最终校验；速度使用实际已收字节与经过时间计算，停顿也计入时间。

整个 BIN 的预期 SHA-256 一致前，24 字节可执行头保持擦除状态；之后再进行镜像验证、
回读及 VALID 记录提交。传输失败、验证失败或确认取消后，Zion 会自动擦除本次 APP
及独占 DATA，并移除空间预留；保留原失败原因，同时提示空间已回收。
清理失败或中断时可能留下未完成预留，可从管理中删除或重试安装。
最终提交状态不确定时，先重新读取两份 A/B 记录；证明已有效安装的内容予以保留并修复
运行时分区表，记录无法读取时不会据此执行破坏性清理。
同 URL 重装会替换原 APP 和资源，失败时不保留该旧版本；其他玩法及系统分区不在其分配范围内。
安装期间暂时关闭 Wi-Fi modem sleep，结束后恢复。当前官方下载接口不支持 Range 续传，
因此不会把重新返回 `200` 的整包错误追加到半包后面。

不支持或无法分配空间的包显示“无法安装”，进入存储准备后的错误显示“安装失败”。
两者都保留已知信息、最后进度和分层中文原因，未知占用不会显示为零。
失败信息持续展示，直到用户返回或开始下一次安装，不会被社区二维码遮盖。
安装中长按 OK 仍可打开取消确认。

完整合并 BIN 会先被解析；源包中的 `0x10000`、`0x20000` 不会直接作为设备目标
地址。支持的资源分区会重定位，只在所属子玩法启动时暴露。因此下载包大小与
安装占用可能不同。继承的旧版 USB 网页分配器会拒绝此 2 MiB 布局，不能作为
当前产品安装通道。

## 构建和升级启动器

主目录是 `folo-ai-passport-zion-main`。激活 ESP-IDF 5.5.3 后，Windows 原生构建：

```powershell
./tools/build-zion.ps1
```

产物位于 `dist/<版本>/<ELF前缀>/`，清单包含实际哈希、目标、布局和测试控制标记，
并保留匹配的 ELF/MAP。`zion-full.bin` 是从 `0x0` 写入的可启动合并镜像；
`app.bin` 不能从 `0x0` 写入。

独立、显式的刷写命令会保留相同布局的玩法和设置：

```powershell
python tools/flash_zion.py --port COM5 --package dist/<版本>/<ELF前缀>
```

端口和目录以实际值为准。旧 1.44 MiB 布局会被拒绝；`--fresh` 明确清除玩法和设置，
用于切换布局，仍保留身份分区，不是日常升级参数。不需要整片擦除。
更改默认配置后，要使用新的构建配置或有意重新生成；旧缓存配置不代表已验证的
产品构建。正常交付包不启用按键注入。

## 哪些测试不能混为一谈

构建、主机测试、协议重放真机安装、官方手机端验收是不同结果。合成按键会经过
实际按键队列、菜单和 LVGL 对象，但不验证实体 ADC 按键。通过 STA 访问配置
HTTP 服务，不代表手机已经成功关联设备热点。

实体显示、字体和扫码、官方手机点击安装流程，以及各个子玩法的云端功能，都
需要独立验收。当前精确结果和剩余项目见交付验证报告。

直接从 `0x0` 写入合并镜像会覆盖其范围内的配置；需要保留现有设置时使用分段刷写工具。
