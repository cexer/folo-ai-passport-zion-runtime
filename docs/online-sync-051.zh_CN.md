# Runtime 0.5.1：同步产品版本

源码：[cexer/folo-ai-passport-zion-runtime](https://github.com/cexer/folo-ai-passport-zion-runtime)，
分支 `feature/shared-runtime`。合并产品 0.4.5、0.4.6 提交，同时保留 ESP-IDF 6.0.1、
公共提供者、外部插件和内置小智。

安装进度黄色，失败及原因红色，完成绿色。短按 OK 启动这次完成的安装，
长按 OK 返回列表，兼容普通槽位和插件负数槽位。启动器不自动启动应用，
手机重启请求也不触发自动启动，方便继续安装。

Zion 字体（含完整中文回退）均为 4bpp；完整字库使用无损压缩。
真实 LVGL 对全部 6,873 字形解码，A8 校验值与独立生成的未压缩参考一致；
单次最大临时分配 15 字节。完整字体目标文件从 214,175 增至 643,639 字节，
另增加 32,812 字节界面子集。之前 2,930,128 字节的 DeviceTest 基座与本次发布
配置不同，这组对比不能当作真机性能或应用运行内存验收。

**新实验布局：**factory 在 `0x10000`，大小 `0x342000`；pool_0 在 `0x352000`，
大小 `0x4000`。身份区、store、pool_1、otadata 地址不变。APP 为 3,387,632 字节，
自身分区余量 28,432 字节。不能视为无损原地升级：旧 pool_0 的内容可能与扩大后的
factory 重叠。需规划全新布局后重新安装，并按精确宿主契约重新构建插件。
本轮未刷机、未迁移设备。

构建及产物核验、30 组针对性主机检查、真实 LVGL 字形解码通过。完整仓库检查仍被
继承的小智 Markdown 语言/配对规则拦截，未修复这些问题。本同步固件未做真机测试。
线上 0.4.6 仍保留原有 2MiB factory 布局。

电源键控制硬件供电，固件无法读取；独立玩法运行时 Zion 也不在执行，
本次管理器更新无法提供所有玩法中的“电源＋上键”软重启。
保留现有开机时按住上键进入列表的方式。
